# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's security
advisories: on this repository, open **Security → Report a
vulnerability** (<https://github.com/KristiyanDDimitrov/Seeker/security/advisories/new>).
Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the Seeker version
(**About Seeker** in the app, or the commit you built from).

## Scope

This repository: the `seeker` CLI, the `seeker-ui` desktop app, the
packaged macOS build, and the Docker Compose template Seeker uses to
run slskd. Vulnerabilities in slskd itself, Soulseek, Spotify or other
third-party software belong with their own maintainers.

## Supported versions

Only the latest release receives fixes.
