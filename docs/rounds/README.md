# Rounds (moved)

The round archive moved on 2026-10-17, when development was grouped
into phases:

- `docs/rounds/round-01/` … `round-12/` are now
  [`docs/phase-01/round-01/`](../phase-01/README.md) … `round-12/`.
  The files kept their names and content.
- New rounds live under their phase: round 13 onwards is in
  [`docs/phase-02/`](../phase-02/README.md).

A path written as `docs/rounds/round-NN/FILE.md` (in a HISTORY entry, a
commit message or an archived brief) resolves to
`docs/phase-01/round-NN/FILE.md`. HISTORY entries keep the path that was
true when they were written; they are a record, so they are not
rewritten.
