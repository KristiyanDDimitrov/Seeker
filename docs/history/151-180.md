### 151 — Round 11 S12 part 1 (§12.1, §12.2, §12.4): the poll says slskd is down; a Start slskd that never guesses

**Findings:** A-11 (an unreachable slskd was invisible). §12.3 (the UI
notices and tray edge-triggering) and §12.5 (A-58, first-session
download notifications) are not done; S12 stopped at its named split

**What was wrong.** `DownloadService.poll_downloads` wrapped each
request in `except Exception`. With slskd refusing connections, every
`get_download_status` raised `httpx.ConnectError`, each one was counted
in `counts["failed"]`, and the poll returned normally: nothing told
anyone that slskd was down. Two further effects found reading the code:

- A due `locked` row's retry went through `_retry_locked_request`,
  whose `except Exception` branches call `_advance_locked_retry`
  before re-raising. So every 20 s poll during an outage spent one of
  the row's `LOCKED_RETRY_MAX_ATTEMPTS` (8) attempts against a peer it
  never reached. An outage longer than the backoff sum could turn a
  merely locked file `unavailable`.
- `seeker downloads status` got no error at all, only inflated
  `Failed:` counts.

**Failing tests first** (`tests/test_download_service.py`, a fake
client raising `httpx.ConnectError` from `get_download_status` and

```
E       Failed: DID NOT RAISE SlskdUnreachableError
E       Failed: DID NOT RAISE SlskdUnreachableError
2 failed, 111 deselected
```

**Fix (`ab23d51`).** `soulseek/client.py` gains
`SlskdUnreachableError(base_url)`. Its message is the one sentence the
UI and CLI show: "SoulSeek isn't reachable — downloads are paused until
slskd is running." `poll_downloads` catches `httpx.TransportError` in

the first refusal aborts the poll, so no request is counted and no row
changes. `_retry_locked_request` re-raises a transport error *before*
`_advance_locked_retry`, so the retry budget is spent only on attempts
that reached slskd. Tests after: `113 passed`. A transport error covers

reported the same way as slskd refusing.

**CLI (§12.4, `95a344a`).** `cli.run` adds `SlskdUnreachableError` to
its caught errors. Before: a traceback. After: exactly the sentence on
stdout and exit status 1. The test asserts the whole of stdout, so a
"Details:" line or any other extra would fail it.

**Start slskd (§12.2, `fa4a1e7`).** `Application.restart_slskd()`

```python
"""Move seeker modules into a package and rewrite every reference.

Usage: python regroup.py <package>   (files | audio | soulseek)

Run from the repo root. Rewrites, in order of specificity:
  1. `from seeker import <old>`  -> `from seeker.<pkg> import <new> as <old>`
     (aliased, so every use of the bound name stays valid)
  2. dotted `seeker.<old>`       -> `seeker.<new>` (imports, patch strings,
     mypy overrides)
  3. path `seeker/<old>.py`      -> `seeker/<new>.py` (ruff per-file-ignores,
     prose)
  4. bare prose `<old>.py`       -> `<new>.py` relative to `seeker/`
"""
import re
import subprocess
import sys
from pathlib import Path

PLANS: dict[str, list[tuple[str, str]]] = {
    "files": [
        ("atomic_file", "files.atomic"),
        ("file_deletion", "files.deletion"),
        ("file_placement", "files.placement"),
        ("filename_sanitize", "files.sanitize"),
        ("filename_format", "files.naming"),
    ],
    "audio": [
        ("audio_analysis", "audio.analysis"),
        ("audio_fingerprint", "audio.fingerprint"),
        ("audio_formats", "audio.formats"),
        ("metadata", "audio.tags"),
        ("library.audio_quality", "audio.quality"),
    ],
    "soulseek": [
        ("docker_setup", "soulseek.docker_setup"),
        ("sharing_service", "soulseek.sharing_service"),
    ],
}

ROOT = Path.cwd()
SEEKER = ROOT / "src" / "seeker"


def targets() -> list[Path]:
    return [
        *sorted((ROOT / "src").rglob("*.py")),
        *sorted((ROOT / "tests").rglob("*.py")),
        ROOT / "pyproject.toml",
        ROOT / "packaging" / "seeker.spec",
        ROOT / "docker-compose.yml",
        ROOT / "CLAUDE.md",
        ROOT / "README.md",
    ]


def rel(dotted: str) -> str:
    return dotted.replace(".", "/") + ".py"


def rewrite(text: str, old: str, new: str) -> str:
    old_parent, _, old_name = old.rpartition(".")
    new_parent, _, new_name = new.rpartition(".")
    from_old = "seeker" + (f".{old_parent}" if old_parent else "")
    alias = "" if new_name == old_name else f" as {old_name}"
    text = re.sub(
        rf"^(\s*)from {re.escape(from_old)} import {old_name}$",
        rf"\1from seeker.{new_parent} import {new_name}{alias}",
        text,
        flags=re.M,
    )
    text = re.sub(
        rf"(?<![\w.])seeker\.{re.escape(old)}\b", f"seeker.{new}", text,
    )
    text = re.sub(
        rf"(?<![\w.])seeker/{re.escape(rel(old))}", f"seeker/{rel(new)}",
        text,
    )
    if old_parent:
        text = re.sub(
            rf"(?<![\w./]){re.escape(rel(old))}", rel(new), text,
        )
    return re.sub(
        rf"(?<![\w./]){re.escape(old_name)}\.py\b", rel(new), text,
    )


def main(package: str) -> None:
    plan = PLANS[package]
    init = SEEKER / package / "__init__.py"
    if not init.exists():
        init.parent.mkdir(exist_ok=True)
        init.touch()
        subprocess.run(["git", "add", str(init)], check=True)
    for old, new in plan:
        if (SEEKER / rel(new)).exists():
            continue
        subprocess.run(
            ["git", "mv", str(SEEKER / rel(old)), str(SEEKER / rel(new))],
            check=True,
        )
    for path in targets():  # after the moves
        if not path.exists():
            continue
        before = path.read_text()
        after = before
        for old, new in plan:
            after = rewrite(after, old, new)
        if after != before:
            path.write_text(after)
            print(f"rewrote {path.relative_to(ROOT)}")


if __name__ == "__main__":
    main(sys.argv[1])
```

def measure(label, fn):
    fn()  # warm
    times = []
    for _ in range(runs):

    tracemalloc.start()
    fn()

          f"p95 {sorted(times)[int(len(times)*0.95)-1]:.2f} ms, "
          f"peak alloc {peak/1e6:.2f} MB, result {len(fn())}")

measure("history get_recent_events", lambda: hist.get_recent_events())

- `resizeRowsToContents` moved from `size_action_column` to the end of
